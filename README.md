# Ceesaxp Homebrew Tap

Homebrew tap for [Ceesaxp](https://github.com/Ceesaxp) apps and tools.

## Casks — native macOS apps

```sh
brew install --cask ceesaxp/tap/<cask>
```

- **gridka** — native macOS CSV viewer for very large files ([repo](https://github.com/Ceesaxp/gridka))
- **writ** — native macOS Markdown editor for technical writing ([repo](https://github.com/Ceesaxp/Writ.app))

## Formulae — command-line tools

```sh
brew install ceesaxp/tap/<formula>
```

- **tele-tui** — keyboard-first Telegram client for the terminal, plus an MCP
  server and a REST API over the same account
  ([repo](https://github.com/Ceesaxp/telegram-cli) ·
  [about](https://ceesaxp.github.io/telegram-cli/)). macOS and Linux, Intel and
  ARM. Installs three binaries: `tele-tui`, `telegram-mcp`, `telegram-api`.
